# Development Roadmap

The repository contains the detailed reusable-knowledge architecture and project documentation under docs.

Priority areas:

1. Canonical doctrine and case-law tagging
2. Cross-topic references without duplicated content
3. Current-law versioning
4. Exam-oriented explanations
5. Searchable legal glossary
6. Source and citation quality checks
7. Tamil/English terminology QA
8. Regression review after legal-content updates
