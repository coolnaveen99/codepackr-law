# Analytics Privacy Policy (Phase 22)

## Allowed (aggregate only)

- Tool opened (slug)
- Workflow completion (opaque key)
- Feature use counts (opaque key)
- Anonymous performance counters (future)

## Never collect

- Legal query text
- Case facts
- Client names
- Uploaded document contents
- Private notes
- Draft contents

## Storage

Metrics live in `cp-law:analytics:v1` in the browser. Users can view and clear them via **Privacy-safe usage metrics**. Prefer opt-in or local-only analytics; do not send legal data to third-party trackers.
