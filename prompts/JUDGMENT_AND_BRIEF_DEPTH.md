# CodePackr Law — Judgment and Brief Depth (add to every authoring prompt)

Paste this block into any new-topic or upgrade prompt.

```text
JUDGMENT AND BRIEF DEPTH (MANDATORY FOR NEW TOPICS)

1. Case Brief (draftingCategory: brief) = 500-700 words of IRAC sentences. Not a heading list.
2. Each new topic ships at least TWO verified judgments.
3. Each leading judgment gets a ~2-page case note (900-1200 words): facts, issue, both sides, decision, ratio, what was not decided, use on this topic. Official 40-page reports are NOT pasted.
4. cases[] must not be empty. Fields: name, year, citation, court, facts, issue, ratioDecidendi, holding, relevance.
5. The brief must cite those cases with citation + ratio + one application sentence.
6. Existing topics are upgraded one file at a time. Do not bulk-rewrite.
7. Never invent citations. Flag unverified items as needs-review.
```
